# mise

> *From "mise en place" — the chef's practice of preparing everything before cooking.*

A recipe sharing platform for home cooks. No ads, no algorithms — just good food shared with intention.

## Features

- **Recipes** — create, edit, fork, import from URL, print view, ingredient scaling, cooking timers
- **Social** — likes, bookmarks, comments, star ratings, follow chefs, real-time notifications
- **Collections** — organize bookmarks into named collections
- **Auth** — email/password + Google OAuth, password reset, custom avatars

## Tech Stack

- **Frontend**: React 19, TanStack Router, Tailwind CSS
- **Backend**: Convex (database, auth, file storage, real-time)
- **Testing**: Vitest, Playwright

## Getting Started

```bash
bun install

# Terminal 1 — backend
bunx convex dev

# Terminal 2 — dev server
bun dev
```

Open [http://localhost:3000](http://localhost:3000)

## Environment Setup

`VITE_CONVEX_URL` is auto-generated by `convex dev`.

For production, set these in the [Convex dashboard](https://dashboard.convex.dev):

```
SITE_URL           # production URL
AUTH_GOOGLE_ID     # Google OAuth client ID
AUTH_GOOGLE_SECRET # Google OAuth client secret
```

## Development

```bash
bun dev              # start dev server
bun build            # production build
bun start            # preview build

bun typecheck        # check types
bun lint             # lint code
bun lint:fix         # fix lint issues

bun test             # run tests (watch mode)
bun test:run         # run tests (CI)
bun test:coverage    # test coverage
bun test:e2e         # E2E tests
```
